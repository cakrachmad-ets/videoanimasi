# Salinan halaman masuk kelas

Salinan halaman masuk dari kelas.motionformat.com, ditambah kolom **Nama** di awal form.

- `index.html`: versi dengan kolom Nama. Nama disimpan di browser (`kelas-nama:<produk>`) dan dipakai sebagai nama pengguna di dalam kelas setelah masuk.
- `index.asli.html`: salinan asli tanpa perubahan.

Isi kelas (Beranda, dll.) tidak ada di file ini; halaman memuatnya dari Supabase Storage setelah login.
